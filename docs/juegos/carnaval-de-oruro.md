# Carnaval de Oruro

Desde el 21 de octubre de 2026 el juego `oruro` es **La Entrada**: el Carnaval de Oruro contado por fraternidades, con cinco bailes, la presentación frente al palco con el nombre de cada uno y el contrapunto con duda. Ver [la-entrada.md](la-entrada.md).

La versión anterior, una sola comparsa de la Diablada donde en cada cuadra se quedaban algunos, está en la historia de git de este archivo.
